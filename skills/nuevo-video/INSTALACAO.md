# Nota de instalação (Muse)

Esta skill faz parte do projeto **claude-skills-shorts-animados** (GitHub: miguelcotrinaia/claude-skills-shorts-animados), clonado em:

`~/workspace/github-skills/claude-skills-shorts-animados/`

Os comandos citados na skill (`npm run estado`, `npm run render`, etc.) rodam DENTRO dessa pasta do projeto — as skills dependem do template Remotion, dos perfis e dos scripts de lá. Vozes de IA são via ElevenLabs (pago, opcional, exige chave do usuário no `.env` do projeto); sem voz, o render sai como prévia silenciosa `out/<id>-SIN-VOZ.mp4`.
