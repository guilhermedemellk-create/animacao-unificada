# Muse Dark Video Production — Skill

Skill de produção audiovisual para vídeos narrativos de suspense com estética gráfica vermelho/preto, inspirada nas características gerais do vídeo de referência fornecido pelo usuário.

## Instalação no Muse
1. Extraia o ZIP no computador.
2. Abra o Muse Chat ou a área de Skills/Knowledge, se sua versão tiver esse recurso.
3. Se existir instalação de Skills, importe a pasta `muse-dark-video-production` ou o arquivo `SKILL.md`, conforme o formato aceito pela interface.
4. Se não existir instalador de Skills, anexe `SKILL.md` à conversa e também os arquivos de `references` relevantes. Anexe os templates quando for iniciar um projeto.
5. Envie a mensagem abaixo.

### Mensagem inicial para o Muse
"Leia o SKILL.md e todos os arquivos da pasta references. Use-os como regras de produção para este projeto. Primeiro, informe quais arquivos conseguiu ler e quais ferramentas consegue realmente executar nesta conversa. Não diga que gerou ou verificou um vídeo sem concluir a ação. Para qualquer vídeo novo, siga o fluxo por fases e valide o teste visual e a narração antes da produção completa."

## Importante
A skill é um conjunto de instruções e modelos. Ela não instala ferramentas de vídeo, não concede acesso ao Blender/FFmpeg e não altera limites do Muse. A execução depende dos recursos disponíveis na conta e na conversa.
